このフォルダに音声ファイルを置くと差し替わります（無い場合はSE=合成音、BGM=無音）。

■ se/{name}.mp3 …効果音の差し替え
  tap / decide / meter / perfect / appeal / star / satisfied / warning

■ bgm/{scene}.mp3 …BGM（ループ再生。置かない限り鳴らない）
  home（ホーム等） / audition（オーディション中）
  review（スキルパネル） / unit（編成・プロデュース設定）

音量・ON/OFFはホーム右上の⚙から。BGMはファイルが無い場合は内蔵の簡素な合成ループが鳴る（v0.25.8〜・初期ON）。
